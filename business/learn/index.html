6 previews shown

Mentor

How a learning plan takes shape

A mentor describes a task and reviews the steps before a trainee sees them.

Read preview: How a learning plan takes shape
  1. The mentor describes the task and where help may be needed.
  2. For a simple example such as arranging three paper cups, the draft sets out the steps and what the trainee needs to show.
  3. The mentor edits and approves the draft before adding it to the trainee’s plan.
Trainee

How a trainee finds a next step

A trainee sees a mentor-approved focus and practises with support.

Read preview: How a trainee finds a next step
  1. The trainee opens their plan to see what to practise and the steps involved.
  2. They can practise with help before trying it on their own.
  3. When ready, they can ask the mentor to review their progress.
Everyone

How note sharing works

A note stays private within the app unless its author shares it.

Read preview: How note sharing works
  1. The author can save a reflection for themselves.
  2. Choosing to share lets their assigned mentor or trainee read the saved note.
  3. Stopping sharing blocks future access, but cannot erase a copy someone has already seen. System operators can access stored data.
Mentor

How a learning request is reviewed

The mentor considers a request before deciding whether a mark changes.

Read preview: How a learning request is reviewed
  1. The mentor opens a request and checks the skill involved.
  2. They decide whether to approve or decline it.
  3. A request alone does not change a mark.
Everyone

How messages and resources work

Messages stay in KMB. Resource links open in another tab.

Read preview: How messages and resources work
  1. The mentor and trainee use Inbox to ask questions and reply. A message is sent only when they choose to send it.
  2. Before opening an outside link, KMB shows the destination and asks whether to continue.
  3. The website opens in a new tab, leaving KMB open.
Manager

What a manager can see

Managers can see the training outline.

Read preview: What a manager can see
  1. The manager screen does not show learner notes, conversations or individual marks.
  2. These limits apply to the app’s manager role. System operators have separate access to stored data.

Questions & answers

Common questions.

A few things to know before getting in touch.

Can I use KMB today?

Not yet. Contact Joseph if you’d like to discuss the project or possible future testing.

Has this been validated in a workplace?

No. So far, testing uses invented people and information. Before a workplace trial, we need to agree how people and their information will be protected.

Does AI approve a learning plan?

No. The mentor approves the plan. The current test version uses scripted drafts and is not connected to a live AI service.
